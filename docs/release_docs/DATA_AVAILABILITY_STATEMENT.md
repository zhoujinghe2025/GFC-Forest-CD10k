# Data Availability Statement Draft

GFC-Forest-CD10k Candidate v1.0 will be released for non-commercial research use under the Creative Commons Attribution-NonCommercial 4.0 International License (CC BY-NC 4.0). The dataset contains fixed pre-change images, post-change images, pixel-level label masks, train/validation/test splits, metadata, and SHA-256 checksums. The construction and evaluation scripts will be released under the MIT License.

Users should cite this dataset release and the original upstream data products, including Global Forest Change/Hansen et al., Landsat/USGS, and Google Earth Engine. The dataset is intended for scientific benchmarking and non-commercial research. It should not be used for legal enforcement, commercial deployment, or operational deforestation attribution without independent validation.

The final public repository URL and DOI will be inserted after upload.
